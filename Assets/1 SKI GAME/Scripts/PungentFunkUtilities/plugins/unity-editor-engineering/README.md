# Unity Editor Engineering

Repo-local Codex plugin for Unity Editor extension architecture, systems research, and native tool UX.

The primary skill is `unity-editor-engineering`. It routes between design-brief interpretation, built-in interface analysis, registry/package system research, and implementation review. The goal is to design editor extensions with the judgment of a senior Unity engine/tooling developer: integrate with existing Unity systems first, then build the smallest missing layer.

Useful helper:

```powershell
python plugins/unity-editor-engineering/scripts/search_unity_docs.py "SerializedObject ApplyModifiedProperties"
```

Core skills:

- `unity-editor-engineering`: top-level Unity Editor extension strategy and review.
- `unity-editor-design-brief`: turn a design brief into a Unity-native tool architecture.
- `unity-editor-interface-forensics`: analyse built-in Unity interfaces and extract reusable UI/UX/system patterns.
- `unity-registry-system-atlas`: research built-in modules, Unity Registry packages, released packages, samples, and comparable pipelines before designing new systems.
